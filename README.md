Menadżer subskrypcji

Prosty, klient-side menadżer subskrypcji zrealizowany w HTML/CSS/JS.

Funkcje:
- Dodawanie, edycja i usuwanie subskrypcji
- Aktywacja/dezaktywacja
- Filtrowanie, wyszukiwanie i sortowanie
- Sumowanie łącznego kosztu miesięcznego (roczne przeliczane na miesięczne)
- Eksport i import JSON
- Dane przechowywane w `localStorage`

Uruchomienie:
- Otwórz index.html w przeglądarce (np. dwuklik lub Live Server)

Pliki:
- index.html
- styles.css
- script.js
- README.md
